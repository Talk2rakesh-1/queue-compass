# Research and provenance — 2026-10-15

[Atlassian incident response guidance](https://www.atlassian.com/incident-management/incident-response/best-practices) describes routing and escalation as part of incident operations. This motivated an inspectable routing experiment; no claim is made that this MVP reduces incident response times.

[scikit-learn Naive Bayes documentation](https://scikit-learn.org/stable/modules/naive_bayes.html) documents multinomial Naive Bayes for word-count text classification. This repository implements the standard formula independently using Python's standard library; it does not vendor scikit-learn code.

All fixtures were written for this project. No external text, licensed dataset, model weights, screenshots, or brand assets were copied. Sources are linked, not redistributed.
